# 邵艾伦 × 孙宇晨 四小时深度对谈 · 采访稿整理与观点总结

一份静态阅读版整理稿，把 B 站视频 [BV1gxpb6tEhM](https://www.bilibili.com/video/BV1gxpb6tEhM/) 的 4 小时 22 分访谈重新组织为可读、可检索、可打印的网页。

## 内容结构

| 章节 | 内容 |
| --- | --- |
| 一、访谈概览 | 嘉宾 / 主持人 / 时长 / 主题速览 |
| 二、核心观点总结 | 15 条核心观点 |
| 三、访谈实录 | 按 15 个主题重排的问答稿（可折叠） |
| 四、金句摘录 | 13 条 |
| 五、完整时间轴 | 30 个原片章节时间戳 |

## 技术说明

- 单文件 `index.html`，零依赖、零构建，直接部署即可
- 响应式布局：桌面端侧边目录 + 移动端折叠目录
- 自动跟随系统深色模式（`prefers-color-scheme`）
- 阅读进度条、当前章节高亮、回到顶部
- 打印样式：打印时自动展开全部问答，输出为干净的纸质稿
